Privacy Policy

cat-clips · last updated 23 September 2026

cat-clips is a personal tool operated by a single individual. It has no users other than its owner: there is no sign-up, no hosted service, and no account other than the owner's own. This policy describes what the software does with data belonging to that one account.

Google data the application requests

The application asks for two Google OAuth scopes, and no others:

  • https://www.googleapis.com/auth/youtube.upload — used solely to upload finished video files to the owner's own YouTube channel.
  • https://www.googleapis.com/auth/youtube.readonly — used solely to read back the name of the signed-in channel, so the owner can confirm which channel a video is about to be published to.

How that data is handled

  • The OAuth token is stored in a single file on the owner's own computer. It is never transmitted anywhere except to Google's own API endpoints.
  • No Google user data is collected, stored, sold, shared or transferred to any third party, and none is used to train any model.
  • The application has no server, no database and no analytics. Nothing is logged anywhere except plain text files on the owner's own computer.
  • Revoking access at myaccount.google.com/permissions immediately and permanently stops all of the above. Deleting the local token file has the same effect.

Limited Use disclosure

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data

This website itself sets no cookies, runs no scripts and collects nothing about its visitors.
